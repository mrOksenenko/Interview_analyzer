# Схема `progress/plans/<topic-slug>.lesson.json`

Путь: `progress/plans/<project_id>/<topic-slug>.lesson.json`, где ключ темы `<project_id>/<type>:<topic-slug>`
(пример: тема `acme/grammar:present-perfect` → `progress/plans/acme/present-perfect.lesson.json`).
Ключи смотри: `python3 scripts/progress.py topics <project_id>`.
Приложение (`./start.sh`) читает эти файлы: без них у темы нет кнопок «Урок» и «Тест».

```json
{
  "topic": "acme/grammar:present-perfect-for-duration-present-simple-for-routines",
  "title": "Времена: Present Perfect и Present Simple",
  "intro": "1–2 предложения: что пользователь сказал на интервью и что разберём.",
  "rule": [
    {"h": "Ловушка 1. …", "p": "объяснение по-русски", "ex": ["English example"], "note": "необязательно"}
  ],
  "practice": [ ...8–14 заданий... ],
  "test":     [ ...8–10 НОВЫХ заданий, не повторяющих practice... ]
}
```

## Типы заданий

| type | Поля | Как проверяется |
|---|---|---|
| `choice` | `prompt`, `options` (2–4), `answer` (строка из options), `explain` | точное совпадение |
| `gap` | `prompt` с `____`, `hint`, `accepted` (список), `explain` | пользователь вписывает только пропущенную форму; сравнение без регистра и пунктуации |
| `fix` | `prompt`, `hint`, `accepted` (список целых фраз), `explain` | пользователь вводит всю фразу (исправление или перевод) |

Правила:
- В `accepted` перечисляй **все** разумные верные варианты (числа цифрой и словом, with/without артикль только если это допустимо).
  Сокращения `'ve`, `'m`, `'re`, `'ll` приложение раскрывает само: `I've` = `I have`.
- `explain` — одно предложение по-русски: правило, почему так. Показывается после ответа.
- Опирайся на **собственные цитаты** пользователя из интервью, не на абстрактные примеры. Не выдумывай ошибок, которых не было.
- Открытые задания (пересказ, говорение, письмо абзацем) в приложение не кладём: их даёт Claude в чате.
- `test` содержит ключ в открытом виде (файл локальный); честность — на пользователе.
- Если пользователь жалуется, что верный вариант не засчитан: режим E (проверка `review.jsonl`), добавь вариант в `accepted`.
