# Interview Analyzer

Анализатор английского на собеседованиях. Ты присылаешь запись интервью, а получаешь честный разбор: уровень, ошибки, причины слабых ответов, план работы над ошибками и тесты с прогрессом.

Всё работает **локально**: аудио расшифровывается на твоём компьютере, ключи API не нужны, личные данные в репозиторий не попадают.

## Что умеет

- **Расшифровка записи** (Whisper, локально): текст с таймкодами, паузами, темпом речи и словами-паразитами.
- **Языковой разбор:** времена, предлоги, артикли, порядок слов, структура предложений, лексика. Ошибки группируются в темы, цитаты берутся дословно из твоей речи.
- **Оценка каждого ответа:** «ответ /10» (насколько правильно) и «английский /10» (как это сказано), плюс **общая оценка интервью** из 10.
- **Причина слабого ответа:** язык, непонимание вопроса или незнание темы. Если причина неочевидна, скилл просит объяснить по-русски, что ты хотел сказать, и решает по твоему ответу.
- **План работы над ошибками:** короткое правило, задания на твоих собственных фразах и проверочный тест по каждой теме.
- **Словарь:** слова и выражения из твоих интервью. Тест на слова (ты вводишь перевод на русский): верно — «Молодец!», неверно — слово попадает в твой словарь «на изучении» с переводом, примером и цитатой из интервью. Словарь можно открыть в любой момент, учить по карточкам и повторять; после трёх верных ответов подряд слово считается выученным. Рядом с каждым словом и примером есть кнопка прослушивания. Свои слова можно добавлять вручную, сразу пачкой: они считаются незнакомыми, попадают в «На изучении» и участвуют в тестах.
- **Прогресс:** серия дней, опыт, уровни; тесты по графику 1 → 3 → 7 → 14 дней, зачёт 80 %. Если ошибка вернулась после «освоено», тема открывается заново.
- **Сверка с фидбеком рекрутера**, если он есть (необязательно).

## Проекты и записи

- **Проект** — одна цель, например «Собеседование в Acme». У проекта есть общий план: темы, уроки и тесты.
- **Запись** — одно интервью (одно аудио). В проекте может быть несколько записей.
- При добавлении записи ты называешь новый проект или выбираешь существующий. Для нового проекта Claude составляет новый план. Для существующего он сравнивает новую запись с прошлыми и корректирует план: повторившиеся темы поднимает выше, новые добавляет, давно не встречавшиеся опускает, а историю проверок не теряет.
- Динамика (итог, ошибки на 100 слов, уровень) считается внутри проекта и видна на его странице.

## Как мы поменяли интерфейс

Сначала всё шло в чате: прислал запись, получил разбор, задания и тесты текстом. Это работало, но было неудобно. Поэтому мы **перенесли интерфейс в локальное веб-приложение**, и пользоваться стало заметно удобнее:

- есть главная страница с темами на сегодня, серией дней и опытом;
- разбор интервью выглядит как отчёт: кольца оценок, карточки вопросов, ошибки по категориям;
- уроки и задания проходятся в интерфейсе с мгновенной проверкой и разбором;
- прогресс виден сразу, а не теряется в длинной переписке.

**Сильнее всего смена интерфейса упростила прохождение тестирования.** В чате тест проходить было неудобно: ответы приходилось печатать в переписке, прогресс надо было смотреть отдельно, ответы и ключ лежали рядом в истории, не было таймера и единого итогового разбора. В приложении тест идёт карточка за карточкой с таймером и без подсказок, результат и разбор ошибок показываются в конце, а зачёт и дата следующей проверки записываются сами.

В чате осталось то, что требует «подумать»: разбор новой записи, составление планов и уроков, проверка открытых ответов и спорных вариантов из тестов.

## Быстрый старт

Нужны macOS или Linux, Python 3.9+ и [Claude Code](https://claude.com/claude-code).

```bash
git clone https://github.com/mrOksenenko/Interview_analyzer.git
cd Interview_analyzer
./setup.sh      # один раз: окружение и локальная расшифровка (faster-whisper)
```

**Запуск приложения:**

```bash
./start.sh
```

Откроется `http://127.0.0.1:8765`. Сервер слушает только `127.0.0.1`. Если порт занят: `./start.sh --port 8766`.

**После каждого интервью:**

1. В приложении нажми **«＋ Запись»**: загрузи файл (mp3, m4a, wav, mp4, webm…) или запиши голос с микрофона.
2. Назови проект и выбери: **новый проект** или **добавить в существующий**. Название записи можно не писать.
3. Приложение само расшифрует аудио в фоне (полоса прогресса; страницу можно закрыть).
4. Когда расшифровка готова, нажми «Скопировать запрос» и отправь его Claude Code в чате (открытом в этой папке), например: «Разбери интервью 2026-11-13-acme-1. Проект «Acme» новый: после разбора составь план и уроки».
5. Скилл `interview-analyzer` разметит реплики кандидата, разберёт ошибки, оценит каждый ответ и интервью, обновит прогресс и составит план (для существующего проекта скорректирует его).
6. Результат появится в приложении: разбор, темы, уроки и тесты.

Через чат тоже можно: напиши «Разбери интервью `~/Downloads/call.m4a`, проект …», и Claude расшифрует файл сам.

| Раздел | Что внутри |
|---|---|
| **Главная** | серия дней, опыт и уровень, записи в обработке, темы к проверке сегодня, проекты |
| **Проекты** | список проектов; страница проекта: записи с оценками, динамика итога, план (темы) |
| **＋ Запись** | загрузка файла или запись с микрофона, выбор проекта, модели и ускорения |
| **Разбор** (из проекта) | итоговая оценка из 10, оценки по каждому вопросу, ошибки по типам (времена, артикли, предлоги, прочее), сильные стороны |
| **Темы** | уроки (правило и задания) и тесты по проектам; тест открывается по графику |
| **Письмо** | слова с опечатками: как написал и как правильно, тренировка написания на слух |
| **Словарь** | тест на слова, словарь «на изучении» / «выучено» / «все», карточки, 🔊 произношение с выбором голоса |

Если верный вариант не засчитан в тесте, нажми «Мой вариант тоже верный», потом напиши Claude в чате: «проверь ответы из приложения».

### Типы ошибок

Ошибки делятся на четыре типа: **времена**, **артикли**, **предлоги** и **прочее** (лексика, порядок слов, структура фраз, формы глаголов, согласование; внутри «Прочего» указана точная категория). Тип виден в разборе интервью, на странице проекта (числа по записям), в фильтре вкладки «Темы» и в уроках и тестах: после неверного ответа приложение показывает ваш ответ (он остаётся в поле), правильный вариант и тип ошибки, а в конце теста сводку по типам. Для текстовых заданий тип определяется сравнением с ближайшим вариантом ключа (лишний, пропущенный или заменённый артикль, предлог, форма глагола), для заданий с выбором по теме урока, поэтому в редких случаях это приблизительная оценка.

### Правописание

Опечатка не равна ошибке по теме. Если в текстовом ответе (задание урока, тест, перевод в тесте на слова) верно всё, кроме написания слова (лишняя, пропущенная, заменённая или переставленная буква, например `subjcet` вместо `subject`), ответ **засчитывается как верный**, не снижает балл и не ломает серию. Слово при этом попадает во вкладку **«Письмо» (Правописание)**: там видно, как ты написал и как правильно, сколько раз ошибся, а кнопка «Тренировка написания» диктует слово голосом (русские слова: по английскому слову), и после трёх верных ответов подряд оно считается исправленным. В разборе теста опечатки показаны отдельно от типов ошибок (времена, артикли, предлоги, прочее). Если рядом есть и ошибка по теме, она считается как обычно, а опечатка всё равно записывается. Не считаются опечатками формы слова и служебные слова (`work/works`, `in/on`, `a/the`), путаница вроде `lose/loose`, а также слова, у которых отличается первая буква: это грамматика или лексика, а не орфография. Без словаря приложение не отличает опечатку от другого настоящего слова, поэтому в редких случаях близкое слово (`mode` вместо `mood`) тоже примет за опечатку. Слова хранятся в `progress/spelling.json` (не коммитятся).

### Словарь и произношение

**Добавление своих слов.** На вкладке «Словарь» нажми «＋ Добавить слова» и вставь список, по одному слову или выражению на строке (до 200 за раз):

```
subject - объект съёмки
take part in - принимать участие, участвовать
flicker | мерцание | There is no flicker. | Мерцания нет.
```

Разделитель между словом и переводом: ` - `, `=`, `:`, Tab или `|`. Несколько вариантов перевода: через запятую, точку с запятой или слэш (засчитывается любой). После `|` можно добавить пример и его перевод. Если порядок перепутан («перевод - word»), приложение поменяет местами. Перед сохранением виден предпросмотр с проверкой каждой строки. Слова можно сохранить в «Мои слова» или в проект. Если слово уже есть в словаре (например, из интервью), оно просто ставится на изучение. Повторное добавление своего слова обновляет его перевод; удалить своё слово можно в его карточке. Свои слова хранятся в `progress/vocab/manual.vocab.json` (не коммитятся).

Слова берутся из `progress/vocab/<проект>.vocab.json`, который Claude пополняет после разбора каждой записи (формат: `.claude/skills/interview-analyzer/references/vocab-schema.md`, проверка: `python3 scripts/progress.py vocab-check`). Тест на слова приложение собирает само: до 4 слов из словаря «на изучении» и новые слова, всего до 10. Ответ сравнивается с заранее заготовленными вариантами перевода; если твой вариант верный, но не засчитан, нажми «Мой вариант тоже верный» и потом напиши Claude: «проверь ответы из приложения», он добавит вариант в словарь.

**Про произношение.** Кнопка 🔊 использует синтезатор речи твоего устройства (голос выбирается в списке справа вверху на вкладке «Словарь»: Авто US/UK или любой английский голос, установленный в системе; шуточные голоса macOS вынесены в отдельную группу). Если голосов мало, добавь их в настройках системы (macOS: Системные настройки → Универсальный доступ → Устный контент → Системный голос → Управлять голосами). Это не запись живого диктора, и звучание зависит от установленных голосов системы. Приложение ничего не скачивает из интернета и не отправляет слова во внешние сервисы.

### Скорость расшифровки и ускорение MPS

На Apple Silicon расшифровка по умолчанию идёт на GPU через MPS и при любой ошибке сама откатывается на процессор. Мы замеряли на MacBook с M1 Pro, модель `small`, запись 9,6 минуты: **CPU 43 с (≈13× быстрее реального времени), MPS 34–35 с (≈17×)**, то есть MPS быстрее примерно на 20 %. Час записи занимает порядка 4–5 минут. Цифры зависят от компьютера и модели; MPS в библиотеке помечен как экспериментальный, поэтому его можно выключить: «Дополнительно → Ускорение → Только процессор» или `--device cpu` у `transcribe.py`. Тексты MPS и CPU местами различаются (это нормально для Whisper), оба варианта нужно сверять с аудио.

## Структура проекта

| Путь | Что |
|---|---|
| `.claude/skills/interview-analyzer/` | Скилл: инструкции, таксономия ошибок, схемы анализа и уроков, форматы упражнений |
| `scripts/transcribe.py` | Аудио → транскрипт (faster-whisper; MPS на Apple Silicon с откатом на CPU) |

| `scripts/server.py`, `app/` | Локальное веб-приложение: загрузка и запись аудио, проекты, уроки, тесты (стандартная библиотека Python, без сборки) |
| `setup.sh`, `start.sh` | Установка и запуск |
| `progress/` | Твои данные: аудио, транскрипты, анализы, отчёты, уроки по проектам, прогресс (**не коммитятся**, см. `.gitignore`) |

## Приватность

- Аудио и транскрипты обрабатываются локально; загруженные файлы лежат в `progress/audio/` на твоём диске.
- Папка `progress/` целиком в `.gitignore`: твои записи, ошибки и результаты не попадут в репозиторий.
- Сервер приложения принимает запросы только с `127.0.0.1`/`localhost` и проверяет заголовки Host и Origin.
- Для анализа текст расшифровки читает Claude Code, поэтому действуют настройки приватности твоего Claude-аккаунта.

## Ограничения

- Произношение и интонацию по тексту оценить нельзя: анализируются слова, грамматика, структура, связность и паузы.
- Whisper иногда «исправляет» грамматику говорящего и слышит слова неточно (особенно на модели `tiny`). Спорные места скилл помечает «проверить по аудио».
- На коротких записях (меньше 3–5 минут) оценка получается предварительной.
- Тест в приложении проверяется по точному совпадению с ключом; спорные верные варианты проверяются в чате.
- Расшифровка идёт по одной записи за раз; следующие ждут в очереди. Для сложного звука выбери модель `medium` (точнее, но медленнее).
- Запись с микрофона работает в браузерах с поддержкой MediaRecorder и требует разрешения на микрофон. Страница должна открываться с `127.0.0.1` или `localhost`.
- Разбор интервью и составление плана делает Claude Code в чате: из приложения их запустить нельзя, оно подготавливает запрос.
