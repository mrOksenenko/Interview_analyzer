# Interview Analyzer

Анализатор английского на собеседованиях. Ты присылаешь запись интервью, а получаешь честный разбор: уровень, ошибки, причины слабых ответов, план работы над ошибками и тесты с прогрессом.

Всё работает **локально**: аудио расшифровывается на твоём компьютере, ключи API не нужны, личные данные в репозиторий не попадают.

## Что умеет

- **Расшифровка записи** (Whisper, локально): текст с таймкодами, паузами, темпом речи и словами-паразитами.
- **Языковой разбор:** времена, предлоги, артикли, порядок слов, структура предложений, лексика. Ошибки группируются в темы, цитаты берутся дословно из твоей речи.
- **Оценка каждого ответа:** «ответ /10» (насколько правильно) и «английский /10» (как это сказано), плюс **общая оценка интервью** из 10.
- **Причина слабого ответа:** язык, непонимание вопроса или незнание темы. Если причина неочевидна, скилл просит объяснить по-русски, что ты хотел сказать, и решает по твоему ответу.
- **План работы над ошибками:** короткое правило, задания на твоих собственных фразах и проверочный тест по каждой теме.
- **Прогресс:** серия дней, опыт, уровни; тесты по графику 1 → 3 → 7 → 14 дней, зачёт 80 %. Если ошибка вернулась после «освоено», тема открывается заново.
- **Сверка с фидбеком рекрутера**, если он есть (необязательно).

## Как мы поменяли интерфейс

Сначала всё шло в чате: прислал запись, получил разбор, задания и тесты текстом. Это работало, но было неудобно. Поэтому мы **перенесли интерфейс в локальное веб-приложение**, и пользоваться стало заметно удобнее:

- есть главная страница с темами на сегодня, серией дней и опытом;
- разбор интервью выглядит как отчёт: кольца оценок, карточки вопросов, ошибки по категориям;
- уроки и задания проходятся в интерфейсе с мгновенной проверкой и разбором;
- прогресс виден сразу, а не теряется в длинной переписке.

**Сильнее всего смена интерфейса упростила прохождение тестирования.** В чате тест проходить было неудобно: ответы приходилось печатать в переписке, прогресс надо было смотреть отдельно, ответы и ключ лежали рядом в истории, не было таймера и единого итогового разбора. В приложении тест идёт карточка за карточкой с таймером и без подсказок, результат и разбор ошибок показываются в конце, а зачёт и дата следующей проверки записываются сами.

В чате осталось то, что требует «подумать»: разбор новой записи, составление планов и уроков, проверка открытых ответов и спорных вариантов из тестов.

## Быстрый старт

Нужны macOS или Linux, Python 3.9+ и [Claude Code](https://claude.com/claude-code).

```bash
git clone https://github.com/mrOksenenko/Interview_analyzer.git
cd Interview_analyzer
./setup.sh      # один раз: окружение и локальная расшифровка (faster-whisper)
```

**После каждого интервью** открой эту папку в Claude Code и напиши, например:

> Разбери интервью `~/Downloads/call.m4a`, роль Backend, фидбек рекрутера: «…»

Скилл `interview-analyzer` сам:
1. расшифрует аудио (`scripts/transcribe.py`);
2. разметит реплики кандидата и разберёт ошибки;
3. оценит каждый ответ, определит причину слабости и поставит итог интервью;
4. сохранит результат и обновит прогресс (`scripts/progress.py`);
5. составит план с уроками и тестами.

**Приложение** (задания, тесты, разбор, прогресс):

```bash
./start.sh
```

Откроется `http://127.0.0.1:8765`. Сервер слушает только `127.0.0.1`. Если порт занят: `./start.sh --port 8766`.

| Раздел | Что внутри |
|---|---|
| **Главная** | серия дней, опыт и уровень, темы к проверке сегодня, последнее интервью |
| **Интервью** | итоговая оценка из 10, оценки по каждому вопросу, ошибки по категориям, сильные стороны |
| **Темы** | урок (правило и задания) и тест; тест открывается по графику |

Если верный вариант не засчитан в тесте, нажми «Мой вариант тоже верный», потом напиши Claude в чате: «проверь ответы из приложения».

## Структура проекта

| Путь | Что |
|---|---|
| `.claude/skills/interview-analyzer/` | Скилл: инструкции, таксономия ошибок, схемы анализа и уроков, форматы упражнений |
| `scripts/transcribe.py` | Аудио → транскрипт (faster-whisper, CPU) |
| `scripts/progress.py` | Прогресс, интервальные повторы, оценки, дашборд (без зависимостей) |
| `scripts/server.py`, `app/` | Локальное веб-приложение (стандартная библиотека Python, без сборки) |
| `setup.sh`, `start.sh` | Установка и запуск |
| `progress/` | Твои данные: транскрипты, анализы, отчёты, уроки, прогресс (**не коммитятся**, см. `.gitignore`) |

## Приватность

- Аудио и транскрипты обрабатываются локально.
- Папка `progress/` целиком в `.gitignore`: твои записи, ошибки и результаты не попадут в репозиторий.
- Сервер приложения принимает запросы только с `127.0.0.1`/`localhost` и проверяет заголовки Host и Origin.
- Для анализа текст расшифровки читает Claude Code, поэтому действуют настройки приватности твоего Claude-аккаунта.

## Ограничения

- Произношение и интонацию по тексту оценить нельзя: анализируются слова, грамматика, структура, связность и паузы.
- Whisper иногда «исправляет» грамматику говорящего и слышит слова неточно (особенно на модели `tiny`). Спорные места скилл помечает «проверить по аудио».
- На коротких записях (меньше 3–5 минут) оценка получается предварительной.
- Тест в приложении проверяется по точному совпадению с ключом; спорные верные варианты проверяются в чате.
- Транскрипция на CPU: час записи на модели `small` занимает примерно 10–20 минут. Для сложного звука: `--model medium`.
