# Схема словаря `progress/vocab/<project_id>.vocab.json`

Словарь проекта: слова и выражения из интервью и уроков. Приложение строит по нему «Тест на слова»,
словарь «на изучении» и карточки. Проверка файлов: `python3 scripts/progress.py vocab-check`.

```json
{
  "project": "acme",
  "items": [
    {
      "en": "subject",
      "kind": "word",
      "ru": "объект съёмки",
      "accepted": ["объект съёмки", "объект съемки", "объект", "тот, кого снимают"],
      "example": "I turn my subject toward the window.",
      "example_ru": "Я поворачиваю объект съёмки к окну.",
      "note": "Subject — тот, кого или что снимают. Object — предмет вообще.",
      "source": {"session": "2026-11-12-acme-1", "quote": "my object → my subject"}
    }
  ]
}
```

## Поля
- `en` — слово или выражение (`kind`: `word` | `phrase`). Идентификатор слова в приложении: `<project>/<slug en>`; дубли пропускаются.
- `ru` — основной перевод (показывается пользователю); `accepted` — **все** разумные русские варианты, которые должны засчитываться
  (синонимы, ё/е, формы). Ответ сравнивается без регистра и пунктуации, по полному совпадению с одним из вариантов.
  Если пользователь жалуется на несчитанный верный вариант: `progress/inbox/vocab_review.jsonl`, добавь вариант в `accepted`.
- `example` / `example_ru` — предложение с переводом (желательно из контекста пользователя).
- `note` — одна фраза: ловушка или различие (необязательно). `source` — откуда слово: сессия и цитата из речи пользователя (необязательно).

## Какие слова брать
- Слова и выражения, которых **не хватило** пользователю в интервью (в `errors` категории `vocabulary`, в `evidence` ответов), и слова из вопросов рекрутера, которые он не понял.
- Профессиональные термины, которые он должен уверенно знать для своей роли.
- Устойчивые сочетания (предлог + слово, глагол + существительное) из тем плана.
- Не больше 10–20 новых слов за запись; без дублей с уже существующим файлом (проверь перед добавлением); только те, в переводе которых ты уверен.
- Перевод и примеры проверяй дважды: ошибка в словаре учит ошибке.

## Слова, добавленные пользователем вручную
В приложении пользователь добавляет слова пачкой. Они лежат в `progress/vocab/manual.vocab.json` (проект `manual`) или в файле проекта, с полем `"manual": true` и датой `added`.
Не удаляй, не переименовывай и не меняй эти записи без просьбы пользователя; новые слова после разбора записывай в обычный файл проекта. Если пользователь пишет, что слово записано неверно, исправь перевод и `accepted` в его записи.
Слова пользователя считаются незнакомыми: приложение сразу ставит их в статус «на изучении», и они попадают в тесты.

## Опечатки (правописание)
Приложение само записывает слова с опечатками в `progress/spelling.json` (`words`: ключ `en:<слово>` или `ru:<слово>`, поля `right`, `typed`, `count`, `status` learning|fixed). Такой ответ в тесте засчитан как верный. Не редактируй этот файл без просьбы; при разборе ответов из приложения опечатки не считай ошибками по теме.
